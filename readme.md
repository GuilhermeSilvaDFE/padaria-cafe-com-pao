# Desenvolvimento Web — Projeto 
> Data: 24/08/2026
 
## Tema e objetivo 

Nossa equipe decidiu desenvolver  um cardápio digital  para um padaria. 

Um cardápio digital trás vários benefícios, dada sua dinamicidade. Por  exemplo, a facilidade de alterar preços;  remover ao adicionar novos produtos; expor promoções em datas de celebração; e acessibilidade, pois por se tratar de uma aplicação web, basta que o cliente escaneie a câmera do seu smartphone  no QR code  correspondente e terá acesso ao cardápio diretamente no seu celular.

Para esse fim, usaremos pelo menos HTML,  CSS e JS.
